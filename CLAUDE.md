# Claude Code ile devam

Bu klasör Home AI Workstation projesinin tek aktif çalışma kopyasıdır.
Başlamadan `AGENTS.md` dosyasını tamamen oku ve oradaki kurallara uy.
Ardından varsa `work/SESSION.md` dosyasını oku: yapılan işlemler, gerçek test
sonuçları, engeller ve sıradaki adımlar oradadır. Ayrıntılı yerel rapor
`outputs/PREFLIGHT-2026-11-05.md` altında bulunabilir; bu dosyalar Git dışıdır.

Kullanıcıyla Türkçe konuş. Önce mevcut durumu doğrula; kurulumu körlemesine
tekrarlama. Hedef önce localhost üzerinde çalışan Ollama + Open WebUI'dır.
GitHub'a hiçbir şey gönderme. İleri ML/uzaktan erişim fazlarına kendiliğinden geçme.
Önceki bir ajanın kurulum iznini, farklı veya yıkıcı yeni işlemler için sınırsız
yetki sayma. İş bitince test sonuçları ve sonraki adımlarla SESSION.md'yi güncelle.
